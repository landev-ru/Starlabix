🎯 О проекте

Starlabix — это PHP-скрипт для интеграции данных автомобильной сигнализации StarLine в систему мониторинга Zabbix.

Скрипт подключается к официальному API developer.starline.ru, проходит двухэтапную авторизацию и отдаёт телеметрию в формате JSON. Zabbix забирает данные через External Check и раскладывает их на items через JSONPATH.

Для работы требуется AppId и Secret от вашего приложения StarLine — подробная инструкция в разделе Получение доступа к API.

🌐 IP-адрес сервера определяется автоматически. Если в user_data.php не указан $user_ip, скрипт сам узнаёт внешний IP через публичные сервисы. Указывать IP вручную нужно только в особых случаях.

🔑 Получение доступа к StarLine API

Прежде чем приступить к установке, получите AppId и Secret в личном кабинете StarLine. Без них скрипт не сможет авторизоваться в API.

Что такое AppId и Secret?

Это идентификатор и секретный ключ вашего приложения. Открытое StarLine API позволяет владельцам охранных комплексов создавать приложения для управления своими автомобилями. AppId и Secret дают доступ исключительно к вашей машине.

1

Войдите в личный кабинет

Откройте my.starline.ru и авторизуйтесь под своей учётной записью.

2

Перейдите в раздел «Разработчикам»

В верхнем меню личного кабинета найдите и откройте раздел «Разработчикам».

3

Нажмите «Создать приложение»

В открывшемся разделе нажмите кнопку «Создать приложение».

4

Заполните форму «Новое приложение»

В окне «Новое приложение» укажите:

Поле Что указать
Имя приложения Например, Starlabix или Zabbix Monitoring
Описание приложения Например, «Мониторинг сигнализации в Zabbix»

Нажмите «СОХРАНИТЬ».

5

Скопируйте AppId и Secret

После сохранения в разделе «Разработчикам» появится созданное приложение с парой AppId и Secret.

# Пример отображения в личном кабинете:
AppId: 1234
Secret: mvNWuRJadRzHlcIkIjadR9o0Tnf0iMzsCsd

Скопируйте оба значения — они понадобятся при настройке файла user_data.php.

6

Внесите значения в user_data.php

<?php
$user_login = 'user@example.com';
$user_pass = sha1('ваш_пароль');
$user_AppId = '1234';
$user_Secret = 'mvNWuRJadRzHlcIkIjadR9o0Tnf0iMzsCsd';
$user_Secret_md5 = md5('mvNWuRJadRzHlcIkIjadR9o0Tnf0iMzsCsd');
// IP сервера — можно оставить пустым, определится автоматически
$user_ip = '';
?>
💡 Подсказка: $user_Secret_md5 можно сгенерировать командой:
php -r "echo md5('ваш_Secret');"
🌐 Про $user_ip: параметр отправляется в StarLine внутри запроса на логин — это не настройка в кабинете. Если оставить пустым, скрипт сам определит внешний IP через api.ipify.org, ifconfig.me, icanhazip.com или ipinfo.io. Указывайте вручную только если автоопределение не работает (NAT, закрытый исходящий трафик).

🧪 Проверка

После заполнения user_data.php запустите скрипт вручную:

php starlabix.php | jq

Если всё настроено корректно — получите JSON с полями user_info, mobile_devices, obd_params, obd_errors. При ошибке — смотрите раздел FAQ.

🛡️ Безопасность

Никогда не публикуйте user_data.php в открытых репозиториях!

  • Добавьте файл в .gitignore:
    user_data.php
  • Используйте user_data.php.example как публичный образец.
  • Ограничьте права доступа:
    chmod 600 user_data.php
    chown zabbix:zabbix user_data.php
  • Secret — это секретный ключ. Если он скомпрометирован — немедленно удалите приложение в личном кабинете и создайте новое.

🚀 Установка

5 шагов — от клонирования до первого JSON-ответа.

1

Клонируем репозиторий

cd /etc/zabbix/externalscripts/
git clone https://github.com/landev-ru/Starlabix.git
cd Starlabix
2

Права и владелец

chmod +x starlabix.php
chown zabbix:zabbix starlabix.php user_data.php
chmod 600 user_data.php
3

Проверка PHP и allow_url_fopen

php -v
php -i | grep allow_url_fopen
# Должно быть: allow_url_fopen => On => On
4

Заполняем user_data.php

Укажите логин/пароль от my.starline.ru и AppId/Secret, полученные в разделе про API. $user_ip можно оставить пустым:

$user_ip = '';

Проверка запуска

⚠️ Важные замечания

🔴 Безопасность

  • Файл user_data.php содержит пароль и Secret — не коммитьте его в публичный репозиторий.
  • Добавьте user_data.php в .gitignore, используйте user_data.php.example.
  • Ограничьте права: chmod 600 user_data.php.

🟠 IP-адрес

В форме создания приложения на my.starline.ru/developer нет поля «User IP». IP передаётся скриптом в параметре user_ip при вызове /apiV3/user/login.

Скрипт автоматически определяет внешний IP и подставляет его. Ручное указание $user_ip нужно только если автоопределение не работает (NAT, закрытый трафик).

🟡 Лимиты API

StarLine API имеет лимиты. Интервал опроса 5m — оптимально. Не ставьте 1m — рискуете получить блокировку.

🔵 Токен

Токен приложения обновляется при каждом запросе. Если получаете 401 — проверьте AppId, Secret, корректность user_ip.

🟣 Кодировка

Если в alias или can_descr кракозябры — включите расширение iconv в PHP.

⚫ Проверка синтаксиса

Формат JSON может отличаться в зависимости от прошивки устройства и версии API. Перед массовым применением протестируйте на одном устройстве.

❓ FAQ

Ошибка «Ошибка получения кода приложения»

Проверьте:

  1. AppId и Secret корректны и активны.
  2. $user_Secret_md5 действительно md5($user_Secret).
  3. Сервер Zabbix имеет доступ в интернет.
  4. allow_url_fopen = On в PHP.
Скрипт возвращает «Не удалось получить slnet_token»

Причина — неверный логин или пароль. Убедитесь, что:

  • $user_login — точный email от my.starline.ru
  • $user_pass = sha1('пароль') — не забудьте про sha1
  • В аккаунте нет запроса подтверждения по SMS — зайдите вручную на my.starline.ru
Скрипт возвращает «Ошибка подключения к API авторизации»

Скорее всего, проблема с определением IP или сетевой доступностью. Что проверить:

  1. Если $user_ip пуст — скрипт пытается определить внешний IP. Проверьте доступ в интернет:
    curl -s https://api.ipify.org
  2. Если автоопределение не работает — укажите $user_ip вручную в user_data.php (внешний IP сервера).
  3. Если запросы к StarLine таймаутят — смотрите следующую ветку FAQ.
Скрипт зависает / «Connection timed out»

Это сетевая проблема: некоторые IP-адреса StarLine недоступны с вашего сервера. Проверьте:

for ip in $(getent ahostsv4 id.starline.ru | awk '{print $1}' | sort -u); do
  echo -n "$ip: "
  timeout 5 bash -c "echo > /dev/tcp/$ip/443" 2>/dev/null && echo "TCP OK" || echo "TCP FAIL"
done

Если часть IP показывает FAIL — это проблема на стороне StarLine или вашего провайдера. Временное решение — зафиксировать рабочий IP в /etc/hosts:

echo "185.129.96.83 id.starline.ru" | sudo tee -a /etc/hosts
echo "185.129.96.83 developer.starline.ru" | sudo tee -a /etc/hosts

Если ни один IP не отвечает — обратитесь в поддержку StarLine (server@starline.ru) или используйте прокси/VPN с российским IP.

Как добавить второе устройство (второй автомобиль)?
Создайте второй хост Zabbix и разверните вторую копию скрипта с отдельным user_data.php. Если у вас несколько устройств на одном аккаунте — используйте JSONPATH с другим индексом, например $.user_info.devices[1].alias.
Можно ли запускать не на сервере Zabbix, а на отдельном хосте?

Да. Установите Zabbix Agent на отдельный хост, положите скрипт в ExternalScripts и добавьте UserParameter:

UserParameter=starlabix.php,php /etc/zabbix/externalscripts/Starlabix/starlabix.php
JSONPATH не находит поле — что делать?

Запустите скрипт вручную и посмотрите точную структуру:

php starlabix.php | jq .user_info.devices[0]

Некоторые прошивки кладут данные в другой узел (obd_params vs obd_errors). Скорректируйте JSONPATH в шаблоне.
